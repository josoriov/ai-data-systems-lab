# AI & Data Systems Lab

A portfolio project using supplied synthetic consumer-lending data and fictional
example policies for **Lumo**, a buy-now-pay-later company.

The project explores two complementary systems:

- A local lending analytics warehouse using Python, SQL, dbt, and DuckDB.
- Spanish customer-message triage using structured model output and Python
  rules for routing and policy-grounded replies.

The focus is explicit business rules, reproducible local execution, and
inspectable results. The data and policies describe a fictional scenario;
this repository does not represent a production deployment.
